Règlement des dettes et redistribution : les règles, posées puis calculées

De la règle coranique au calcul : report de l'insolvable, remise, prêt sans intérêt, zakat, parts successorales, flux et indice de justice — avec les limites explicites.

13 équations 13/13 contrôles 0 transfert de fonds Corpus : versets cités
Périmètre honnête. Ce module formalise des règles et calcule des exemples. Il ne perçoit aucune zakat, ne détient aucun fonds et ne contraint personne. Les scénarios agrégés sont des modèles déclarés ; la parabole des sept épis n'est pas un rendement. La « complétude complète » est bornée à la complétude du protocole déclaré.

Source normative

Coran 2:275-279, 2:280, 2:282, 2:245, 2:261, 9:60, 4:11-12, 5:8, 16:90, 49:10. Les versets sont cités par référence et paraphrasés ; aucune traduction n'est présentée comme officielle. Les constantes de zakat et de nisab sont celles du moteur du dossier.

Cartes d'explication

Chaque carte pose la règle, donne le résultat et explique ce qu'elle dit — et ce qu'elle ne dit pas.

EQ-01OPÉRATIONNEL

La zakat légale : seuil et taux

La zakat est 1/40 (2,5 %) de la richesse au-dessus du nisab ; le nisab argent du dossier est de 595 g.

Z = τ·A·1[A ≥ N] ; τ = 1/40 ; N = 595 g (Ag)

Résultat : Z(1 000 €) = 25.000000 € · Z(500 €) = 0.000000 € · N = 517.391304 €

Sous le seuil, la zakat est nulle : la règle protège les petits patrimoines. Les montants utilisent l'étalonnage du dossier, pas les cours réels.

reglement_dettes_redistribution.py → zakat_legale() → C01

EQ-02SPÉCIFIÉ

Les huit catégories coraniques

Le verset 9:60 énumère huit catégories : les pauvres, les nécessiteux, ceux qui ont la charge de la collecte, ceux dont les cœurs sont à rallier, l'affranchissement, les endettés, la cause de Dieu et le voyageur.

Q 9:60 ; k = 1..8 ; Σ_k s_k = 1 ; s_k ≥ 0

Résultat : s_k = 1/8 (k = 1..8) · Σ_k s_k = 1

Le Coran fixe les catégories, pas des parts égales. Le module retient 1/8 par catégorie comme convention de calcul déclarée ; la somme vaut 1.

reglement_dettes_redistribution.py → categories_coraniques() → C02

EQ-03OPÉRATIONNEL

Report et remise

Le verset 2:280 demande de reporter l'échéance du débiteur insolvable et déclare la remise meilleure. Formule : reste = dette − versé − remis, jamais négatif.

D' = D − min(C, D) − F ; 0 ≤ F ≤ D − min(C, D) ; D' ≥ 0

Résultat : D' = 500.000000 € · F = 0 € ⇒ D' = 0 € · F_max = 700.000000 €

La remise ne peut dépasser le reste dû ; une demande supérieure est plafonnée. Le module ne juge pas la bonne foi et ne contraint personne.

reglement_dettes_redistribution.py → reglement_insolvabilite() → C03

EQ-04OPÉRATIONNEL

Qard hasan contre riba

Le prêt d'honneur restitue le capital sans surplus : R = C. Le prêt à intérêt compose : R = C(1+r)^n.

qard : R = C ; ribā : R = C(1+r)^n ; ΔR = R − C

Résultat : R_qard = 10 000.000000 € · R_ribā(5 %, 10 a) = 16 288.946268 € · ΔR = 6 288.946268 €

Pour 10 000 à 5 % sur 10 ans, le surcoût est 6 288,95. Le moteur rejette tout taux de riba positif.

reglement_dettes_redistribution.py → qard_hasan_vs_riba() → C04

EQ-05SIMULÉ

Capacité de remboursement

Capacité = revenu − dépenses essentielles, jamais négative ; durée = arrondi supérieur de la dette sur la capacité.

C = max(0, Y − E) ; v = min(C, D) ; n = ⌈D/C⌉ (C > 0)

Résultat : C = 800.000000 €/a · n = 5 a · C = 0 ⇒ 2:280

Si le revenu est inférieur aux dépenses, la capacité est nulle : le résultat est un report, pas une contrainte. La frontière des dépenses essentielles est une convention déclarée.

reglement_dettes_redistribution.py → capacite_remboursement() → C05

EQ-06OPÉRATIONNEL

Parts successorales fixes

Cas déclaré : conjoint, père, mère, un fils, une fille, après dettes. Conjoint 1/8, père 1/6, mère 1/6, reste 13/24 partagé 2:1.

s1 = 1/8 ; s2 = 1/6 ; s3 = 1/6 ; R = 13/24 ; s4:s5 = 2:1

Résultat : Σ s = 1 · s4/s5 = 2 · s1 = 9 000.000000 €

La somme vaut exactement 1. Ce n'est pas un calculateur général : awl, radd et autres cas sont exclus.

reglement_dettes_redistribution.py → succession_fixes() → C06

EQ-07SIMULÉ

La zakat comme stabilisateur

Sur une masse W, l'injection annuelle vaut 2,5 % de W et la masse tourne en 40 ans à flux constant.

I_Z = τ·W ; 1/τ = rotation

Résultat : I_Z = 25 000 000 000.000000 € · 1/τ = 40.000000 a

Modèle agrégé sans comportement des agents ni croissance ; ce n'est pas une prévision économique.

reglement_dettes_redistribution.py → zakat_stabilisateur() → C07

EQ-08SIMULÉ

Redistribution et inégalité

Deux groupes égaux : Gini = (a−b)/(2(a+b)) ; un transfert t le réduit de t/(a+b).

G = (a−b)/(2(a+b)) ; G' = G − t/(a+b) ; t* = (a−b)/2

Résultat : G = 0.250000 → 0.125000 (t = 25) → 0.000000 (t = 50)

Exemple : 0,25, puis 0,125, puis 0 à l'égalisation complète. Modèle-jouet, pas une mesure de la distribution réelle.

reglement_dettes_redistribution.py → redistribution_inegalite() → C08

EQ-09SPÉCIFIÉ

La parabole de l'abondance

Verset 2:261 : un grain devient sept épis, chacun portant cent grains : 7 × 100 = 700.

7 × 100 = 700 ; 700·Z (illustration)

Résultat : 7 × 100 = 700 · 700·Z = 17 500.000000 € (Z = 25.000000 €)

C'est une parabole révélée, pas un rendement financier ni une promesse de multiplication ; elle n'entre dans aucun calcul de solvabilité.

reglement_dettes_redistribution.py → parabole_abondance() → C09

EQ-10OPÉRATIONNEL

Continuité du flux

Stock après n années : W_n = W_0(1−τ)^n ; demi-vie = ln(0,5)/ln(0,975) ≈ 27,38 ans.

W_n = W_0(1−τ)^n ; n½ = ln(1/2)/ln(1−τ)

Résultat : n½ = 27.377851 a · W(40)/W0 = 0.363232

La continuité vient du flux, pas de l'accumulation. Le modèle est sans croissance et sans inflation.

reglement_dettes_redistribution.py → continuite_zakat() → C10

EQ-11OPÉRATIONNEL

Conservation du flux

Zakat = somme des allocations + réserve ; la réserve est une fraction déclarée de la zakat.

Z = Σ_k A_k + R ; A_k = (1−ρ)·Z/8

Résultat : Z = 25.000000 € = Σ A_k (22.500000 €) + R (2.500000 €)

Identité comptable : aucune unité ne disparaît du circuit déclaré. Le taux de réserve est une convention de gouvernance.

reglement_dettes_redistribution.py → conservation_flux() → C11

EQ-12SPÉCIFIÉ

Indice de justice et de paix

J = 1 − T, avec T = 0,40 riba + 0,20 partage + 0,20 zakat + 0,20 adossement.

J = 1 − T ; T = 0.40·t_riba + 0.20·t_partage + 0.20·t_zakat + 0.20·t_adossement

Résultat : T = 0 : J = 1.000000 · T = 0.680000 : J = 0.320000

Scénario halal : J = 1 ; scénario usuraire : T = 0,68 et J = 0,32. Convention interne, pas une mesure de la paix sociale.

reglement_dettes_redistribution.py → indice_justice_paix() → C12

EQ-13SPÉCIFIÉ

Les quatre piliers et la complétude du protocole

P1 identité et mandat, P2 intégrité et provenance, P3 confidentialité et maîtrise, P4 résilience et preuve ; chacun a un répondant dans le protocole de dette.

P1 ↔ S · P2 ↔ H · P3 ↔ R · P4 ↔ A

Résultat : 4/4 · K = 1.000000

K = 4/4 = 1 exprime la complétude du protocole déclaré, pas celle du monde.

reglement_dettes_redistribution.py → ponts_quatre_piliers() → C13

Limites

  • Aucune mesure : le module calcule des règles, il ne mesure ni la pauvreté, ni la paix, ni l'abondance.
  • Aucun transfert : aucun fonds n'est détenu, perçu ou distribué.
  • Nisab calibré : les seuils viennent de l'étalonnage du dossier, pas des cours réels.
  • Succession partielle : un cas déclaré, sans awl, radd ni testament.
  • Modèles agrégés : capacité, stabilisateur et Gini sont des modèles-jouets à hypothèses explicites.
  • Parabole : le facteur 700 n'est pas un rendement.
  • Indice : J = 1−T est une convention interne, pas une mesure de justice.
  • Complétude : K = 1 ne vaut que pour le protocole déclaré.
  • Aucune autorité : le module ne remplace ni un juge, ni un savant, ni une institution de zakat.
