Debt settlement and redistribution: the rules, posed and then computed

From the Quranic rule to the computation: respite for the insolvent, forgiveness, interest-free lending, zakat, inheritance shares, flow and a justice index — with explicit limits.

13 equations 13/13 checks 0 fund transfer Corpus: cited verses
Honest scope. This module formalises rules and computes examples. It collects no zakat, holds no funds and coerces no one. Aggregate scenarios are declared models; the parable of the seven spikes is not a return. “Complete completeness” is bounded by the completeness of the declared protocol.

Normative source

Quran 2:275-279, 2:280, 2:282, 2:245, 2:261, 9:60, 4:11-12, 5:8, 16:90, 49:10. Verses are cited by reference and paraphrased; no translation is presented as official. Zakat and nisab constants come from the project engine.

Explanation cards

Each card states the rule, gives the result and explains what it says — and what it does not say.

EQ-01OPERATIONAL

Legal zakat: threshold and rate

Zakat is 1/40 (2.5%) of wealth above the nisab; the project's silver nisab is 595 g.

Z = τ·A·1[A ≥ N] ; τ = 1/40 ; N = 595 g (Ag)

Result : Z(1 000 €) = 25.000000 € · Z(500 €) = 0.000000 € · N = 517.391304 €

Below the threshold zakat is zero: the rule protects small estates. Amounts use the project calibration, not live market prices.

reglement_dettes_redistribution.py → zakat_legale() → C01

EQ-02SPECIFIED

The eight Quranic categories

Verse 9:60 lists eight categories: the poor, the needy, those employed to collect it, those whose hearts are to be reconciled, to free captives, debtors, in the cause of God, and the wayfarer.

Q 9:60 ; k = 1..8 ; Σ_k s_k = 1 ; s_k ≥ 0

Result : s_k = 1/8 (k = 1..8) · Σ_k s_k = 1

The Quran fixes the categories, not equal shares. The module uses one eighth per category as a declared calculation convention; the sum is one.

reglement_dettes_redistribution.py → categories_coraniques() → C02

EQ-03OPERATIONAL

Respite and forgiveness

Verse 2:280 asks for respite for the insolvent debtor and calls forgiveness better. Formula: remainder = debt − paid − forgiven, never negative.

D' = D − min(C, D) − F ; 0 ≤ F ≤ D − min(C, D) ; D' ≥ 0

Result : D' = 500.000000 € · F = 0 € ⇒ D' = 0 € · F_max = 700.000000 €

Forgiveness cannot exceed the remaining debt; a larger request is capped. The module does not judge good faith and enforces nothing.

reglement_dettes_redistribution.py → reglement_insolvabilite() → C03

EQ-04OPERATIONAL

Qard hasan versus riba

The goodly loan returns the principal with no surplus: R = C. An interest loan compounds: R = C(1+r)^n.

qard : R = C ; ribā : R = C(1+r)^n ; ΔR = R − C

Result : R_qard = 10 000.000000 € · R_ribā(5 %, 10 a) = 16 288.946268 € · ΔR = 6 288.946268 €

For 10,000 at 5% over 10 years, the extra is 6,288.95. The engine rejects any positive riba rate.

reglement_dettes_redistribution.py → qard_hasan_vs_riba() → C04

EQ-05SIMULATED

Repayment capacity

Capacity = income − essential expenses, never negative; duration = ceiling of debt over capacity.

C = max(0, Y − E) ; v = min(C, D) ; n = ⌈D/C⌉ (C > 0)

Result : C = 800.000000 €/a · n = 5 a · C = 0 ⇒ 2:280

If income is below expenses, capacity is zero, so the result is a deferral, not coercion. The essential-expense line is a declared convention.

reglement_dettes_redistribution.py → capacite_remboursement() → C05

EQ-06OPERATIONAL

Fixed inheritance shares

Declared case: spouse, father, mother, one son, one daughter, after debts. Spouse 1/8, father 1/6, mother 1/6, remainder 13/24 split 2:1.

s1 = 1/8 ; s2 = 1/6 ; s3 = 1/6 ; R = 13/24 ; s4:s5 = 2:1

Result : Σ s = 1 · s4/s5 = 2 · s1 = 9 000.000000 €

The sum is exactly one. This is not a general inheritance calculator: awl, radd and other cases are excluded.

reglement_dettes_redistribution.py → succession_fixes() → C06

EQ-07SIMULATED

Zakat as an automatic stabiliser

At aggregate wealth W, the annual injection is 2.5% of W, and the stock turns over in 40 years at constant flow.

I_Z = τ·W ; 1/τ = rotation

Result : I_Z = 25 000 000 000.000000 € · 1/τ = 40.000000 a

An aggregate model without agent behaviour or growth; not an economic forecast.

reglement_dettes_redistribution.py → zakat_stabilisateur() → C07

EQ-08SIMULATED

Redistribution and inequality

Two equal groups: Gini = (a−b)/(2(a+b)); a transfer t lowers it by t/(a+b).

G = (a−b)/(2(a+b)) ; G' = G − t/(a+b) ; t* = (a−b)/2

Result : G = 0.250000 → 0.125000 (t = 25) → 0.000000 (t = 50)

Example: 0.25, then 0.125, then 0 at full equalisation. A toy model, not a measurement of real distribution.

reglement_dettes_redistribution.py → redistribution_inegalite() → C08

EQ-09SPECIFIED

The parable of abundance

Verse 2:261: one grain becomes seven spikes, each with a hundred grains: 7 × 100 = 700.

7 × 100 = 700 ; 700·Z (illustration)

Result : 7 × 100 = 700 · 700·Z = 17 500.000000 € (Z = 25.000000 €)

This is a revealed parable, not a financial return or a promise of multiplication; it enters no solvency calculation.

reglement_dettes_redistribution.py → parabole_abondance() → C09

EQ-10OPERATIONAL

Continuity of the flow

Stock after n years: W_n = W_0(1−τ)^n; half-life = ln(0.5)/ln(0.975) ≈ 27.38 years.

W_n = W_0(1−τ)^n ; n½ = ln(1/2)/ln(1−τ)

Result : n½ = 27.377851 a · W(40)/W0 = 0.363232

Continuity comes from the flow, not from accumulation. The model has no growth and no inflation.

EQ-11OPERATIONAL

Conservation of the flow

Zakat = sum of allocations + reserve; the reserve is a declared fraction of zakat.

Z = Σ_k A_k + R ; A_k = (1−ρ)·Z/8

Result : Z = 25.000000 € = Σ A_k (22.500000 €) + R (2.500000 €)

An accounting identity: no unit disappears from the declared circuit. The reserve rate is a governance convention.

reglement_dettes_redistribution.py → conservation_flux() → C11

EQ-12SPECIFIED

Justice and peace index

J = 1 − T, where T = 0.40 riba + 0.20 sharing + 0.20 zakat + 0.20 asset backing.

J = 1 − T ; T = 0.40·t_riba + 0.20·t_partage + 0.20·t_zakat + 0.20·t_adossement

Result : T = 0 : J = 1.000000 · T = 0.680000 : J = 0.320000

Halal scenario: J = 1; usurious scenario: T = 0.68 and J = 0.32. An internal convention, not a measure of social peace.

reglement_dettes_redistribution.py → indice_justice_paix() → C12

P1 identity and mandate, P2 integrity and provenance, P3 confidentiality and control, P4 resilience and proof; each has a counterpart in the debt protocol.

P1 ↔ S · P2 ↔ H · P3 ↔ R · P4 ↔ A

K = 4/4 = 1 expresses the completeness of the declared protocol, not of the world.

Limits

  • No measurement: the module computes rules; it measures neither poverty, nor peace, nor abundance.
  • No transfer: no funds are held, collected or distributed.
  • Calibrated nisab: thresholds come from the project calibration, not live prices.
  • Partial inheritance: one declared case, without awl, radd or wills.
  • Aggregate models: capacity, stabiliser and Gini are toy models with explicit assumptions.
  • Parable: the factor 700 is not a return.
  • Index: J = 1−T is an internal convention, not a measure of justice.
  • Completeness: K = 1 holds only for the declared protocol.
  • No authority: the module replaces neither a judge, nor a scholar, nor a zakat institution.
