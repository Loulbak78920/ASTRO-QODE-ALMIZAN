13 معادلة 13/13 تحققًا لا تحويل أموال المصدر: آيات مشار إليها
نطاق صادق. هذه الوحدة تصوغ قواعد وتحسب أمثلة. لا تجمع زكاة، ولا تحتفظ بأموال، ولا تُلزم أحدًا. السيناريوهات المجمّعة نماذج معلنة؛ ومثل السبعة سنابل ليس عائدًا. «الاكتمال الكامل» محدود باكتمال البروتوكول المعلن.

EQ-01تشغيلي

الزكاة الشرعية: النصاب والمعدل

الزكاة 1/40 (2.5%) من الثروة التي تبلغ النصاب، والنصاب الفضي في المشروع 595 غرامًا.

Z = τ·A·1[A ≥ N] ; τ = 1/40 ; N = 595 g (Ag)

النتيجة : Z(1 000 €) = 25.000000 € · Z(500 €) = 0.000000 € · N = 517.391304 €

دون النصاب تكون الزكاة صفرًا: القاعدة تحمي صغار المالكين. المبالغ تستخدم معايرة المشروع لا أسعار السوق اللحظية.

EQ-02محدد

الفئات الثماني في الآية

الآية 9:60 تعدّد ثماني فئات: الفقراء، والمساكين، والعاملين عليها، والمؤلفة قلوبهم، والرقاب، والغارمين، وفي سبيل الله، وابن السبيل.

Q 9:60 ; k = 1..8 ; Σ_k s_k = 1 ; s_k ≥ 0

النتيجة : s_k = 1/8 (k = 1..8) · Σ_k s_k = 1

القرآن يحدد الفئات لا أنصبة متساوية. الوحدة تعتمد الثمن لكل فئة كاصطلاح حسابي معلن، والمجموع يساوي واحدًا.

EQ-03تشغيلي

إنظار المعسر والإبراء

الآية 2:280 تطلب إنظار المدين المعسر وتجعل الإبراء أفضل. الصيغة: الباقي = الدين − المدفوع − الإبراء، بلا سالب.

D' = D − min(C, D) − F ; 0 ≤ F ≤ D − min(C, D) ; D' ≥ 0

النتيجة : D' = 500.000000 € · F = 0 € ⇒ D' = 0 € · F_max = 700.000000 €

الإبراء لا يتجاوز الباقي؛ وإذا طُلب أكثر يُقيَّد بالباقي. الوحدة لا تحكم على حسن النية ولا تُلزم أحدًا.

EQ-04تشغيلي

القرض الحسن مقابل الربا

القرض الحسن يعيد رأس المال دون زيادة: R = C. القرض بفائدة يتراكم: R = C(1+r)^n.

qard : R = C ; ribā : R = C(1+r)^n ; ΔR = R − C

النتيجة : R_qard = 10 000.000000 € · R_ribā(5 %, 10 a) = 16 288.946268 € · ΔR = 6 288.946268 €

لعشرة آلاف يورو بفائدة 5% لعشر سنوات، الزيادة 6288.95 يورو. المحرك يرفض أي معدل ربا موجب.

EQ-05محاكى

القدرة على السداد

القدرة = الدخل − النفقات الأساسية، ولا تكون سالبة؛ والمدة = تقريب أعلى للدين على القدرة.

C = max(0, Y − E) ; v = min(C, D) ; n = ⌈D/C⌉ (C > 0)

النتيجة : C = 800.000000 €/a · n = 5 a · C = 0 ⇒ 2:280

إذا كان الدخل أقل من النفقات فالقدرة صفر، فتكون النتيجة إنظارًا لا إلزامًا. حدّ النفقات الأساسية اصطلاح معلن.

EQ-06تشغيلي

الأنصبة الشرعية في الميراث

حالة معلنة: زوج، وأب، وأم، وابن، وبنت، بعد الديون. الزوج 1/8، والأب 1/6، والأم 1/6، والباقي 13/24 للابن والبنت بنسبة 2:1.

s1 = 1/8 ; s2 = 1/6 ; s3 = 1/6 ; R = 13/24 ; s4:s5 = 2:1

EQ-07محاكى

الزكاة كمثبِّت تلقائي

على مستوى الكتلة W، الحقن السنوي = 2.5% × W، ودوران الكتلة 40 سنة عند تدفق ثابت.

I_Z = τ·W ; 1/τ = rotation

النتيجة : I_Z = 25 000 000 000.000000 € · 1/τ = 40.000000 a

نموذج مجمّع بلا سلوك أفراد ولا نمو؛ ليس تنبؤًا اقتصاديًا.

EQ-08محاكى

إعادة التوزيع واللامساواة

نموذج مجموعتين متساويتين: جيني = (a−b)/(2(a+b))، والتحويل t يخفضه بمقدار t/(a+b).

G = (a−b)/(2(a+b)) ; G' = G − t/(a+b) ; t* = (a−b)/2

النتيجة : G = 0.250000 → 0.125000 (t = 25) → 0.000000 (t = 50)

مثال: 0.25 ثم 0.125 ثم 0 عند التسوية الكاملة. هذا نموذج لعبة وليس قياسًا للتوزيع الحقيقي.

EQ-09محدد

مثل الوفرة

الآية 2:261: حبة تصير سبع سنابل، في كل سنبلة مئة حبة: 7 × 100 = 700.

7 × 100 = 700 ; 700·Z (illustration)

النتيجة : 7 × 100 = 700 · 700·Z = 17 500.000000 € (Z = 25.000000 €)

هذا مثل قرآني وليس عائدًا ماليًا ولا وعدًا بمضاعفة الأموال؛ لا يدخل في أي حساب جدوى.

EQ-10تشغيلي

استمرارية التدفق

المخزون بعد n سنة: W_n = W_0(1−τ)^n، ونصف العمر = ln(0.5)/ln(0.975) ≈ 27.38 سنة.

W_n = W_0(1−τ)^n ; n½ = ln(1/2)/ln(1−τ)

النتيجة : n½ = 27.377851 a · W(40)/W0 = 0.363232

الاستمرارية تأتي من التدفق لا من التراكم. النموذج بلا نمو ولا تضخم.

EQ-11تشغيلي

حفظ التدفق

الزكاة = مجموع الأنصبة + الاحتياطي؛ والاحتياطي نسبة معلنة من الزكاة.

Z = Σ_k A_k + R ; A_k = (1−ρ)·Z/8

النتيجة : Z = 25.000000 € = Σ A_k (22.500000 €) + R (2.500000 €)

هوية محاسبية: لا تختفي أي وحدة من الدائرة المعلنة. نسبة الاحتياطي اصطلاح حوكمة.

EQ-12محدد

مؤشر العدل والسلام

J = 1 − T، حيث T = 0.40 ربا + 0.20 مشاركة + 0.20 زكاة + 0.20 أداء عيني.

J = 1 − T ; T = 0.40·t_riba + 0.20·t_partage + 0.20·t_zakat + 0.20·t_adossement

النتيجة : T = 0 : J = 1.000000 · T = 0.680000 : J = 0.320000

السيناريو الحلال: J = 1؛ السيناريو الربوي: T = 0.68 وJ = 0.32. المؤشر اصطلاح داخلي لا يقيس السلام الاجتماعي.

الحدود

  • لا قياس: الوحدة تحسب قواعد ولا تقيس الفقر ولا السلام ولا الوفرة.
  • لا تحويل: لا تُحتفظ بأموال ولا تُجمع ولا تُوزع.
  • نصاب معاير: العتبات من معايرة المشروع لا من الأسعار اللحظية.
  • ميراث جزئي: حالة معلنة واحدة، دون عول أو رد أو وصية.
  • نماذج مجمّعة: القدرة والمثبِّت وجيني نماذج لعبة بفرضيات صريحة.
  • مثل: العامل 700 ليس عائدًا.
  • مؤشر: J = 1−T اصطلاح داخلي وليس قياسًا للعدل.
  • اكتمال: K = 1 لا يصح إلا للبروتوكول المعلن.
  • لا سلطة: الوحدة لا تحل محل قاضٍ ولا عالم ولا مؤسسة زكاة.
