### Conversion MSYS de `ref:chemin` sous Git Bash

La forme `git show "origin/main:$CHEMIN"` échoue sous Git Bash : MSYS réécrit l'argument et Git ne reconnaît plus la révision.

```text
fatal: ambiguous argument 'origin\main;.qoder\skills\fixture-skill\a.txt':
unknown revision or path not in the working tree.
SHOW_EXIT=128
```

Le fixture a donc vérifié l'échec de cette forme, puis la variante retenue :

```bash
oid=$(git -C "$DEPOT" ls-tree -r origin/main -- "$CHEMIN" | awk '{print $3}')
git -C "$DEPOT" cat-file blob "$oid" > /tmp/publie
```

Cette variante a produit le blob attendu et le SHA-256 identique à la source avant dérive. L'étape 6 et le tableau des échecs fréquents ont été corrigés en conséquence. Le script `github_pr_api.py` n'a pas changé.
