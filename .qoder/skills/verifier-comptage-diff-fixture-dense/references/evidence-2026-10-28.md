## 4. Seuil de fusion de `diff -u` (mesuré cette session)

`diff --version` : `diff (GNU diffutils) 3.12`. Fichier de 40 lignes, deux lignes modifiées, écart variable :

| Lignes inchangées entre les deux changements | hunks `diff -u` | hunks `diff -U0` |
|---|---|---|
| 1 à 6 | 1 | 2 |
| 7, 8, 10 | 2 | 2 |

La fusion s'arrête à 7 lignes inchangées : le seuil est `2 × contexte` (contexte 3), pas « strictement moins de 6 ». Une fixture à 6 lignes d'écart exerce encore la fusion.

## 5. Blocs contigus

Deux edits sur des lignes voisines, exécutés avec l'assembleur sur une fixture à frontmatter valide :

```
CHANGED 1
CHANGED_RANGES replace:12-13>12-13
RESULT OK
```

`diff -u` et `diff -U0` donnent chacun 1 hunk. Un compteur de plages ne compte donc pas les edits : il fusionne les lignes contiguës. Écrire « une plage par edit » serait faux.

## 6. Prérequis de la fixture

Une fixture en texte nu, sans frontmatter, est refusée avant toute mesure :

```
APPLY e1 (exact)
APPLY e2 (exact)
FAIL frontmatter: first line is not ---
RESULT FAIL applied=0/2
```

Code 1, aucun brouillon écrit. La fixture doit porter un frontmatter valide, même si le contenu mesuré n'a rien à voir avec le Skill.

## 8. Non vérifié

- la vérité sémantique de la prose qui entoure un compteur ;
- le comportement d'autres implémentations de `diff` (BSD, busybox) : le seuil `2 × contexte` est celui de GNU diffutils 3.12 ;
- les fixtures CRLF, BOM, fichier vide, diff binaire ;
- un compteur d'occurrences sans passage par `diff` ;
- le rechargement runtime du Skill : aucun `/skills reload` n'a été demandé ni constaté.
