## Étape 6 — commandes exactes

Extraction d'OID, refus d'un OID ambigu, et échantillonnage de stabilité (lectures sur `$VERIF`, cf. étape 5) :

```bash
oids="$(git -C "$VERIF" ls-tree -r --format='%(objectname)' origin/main -- "$CHEMIN")"
n="$(printf '%s\n' "$oids" | grep -c . || true)"
printf 'OID_COUNT=%s\n' "$n"
if [ "$n" -ne 1 ]; then
  echo "OID_INVALID $CHEMIN count=$n"
else
  oid="$oids"
  git -C "$VERIF" cat-file blob "$oid" > "$TMP/publie"
  sha256sum "$TMP/publie" "$SOURCE/$CHEMIN"
  stat -c '%y %s %n' "$SOURCE/$CHEMIN"
  for i in 1 2 3; do sha256sum "$SOURCE/$CHEMIN"; stat -c '%y %s' "$SOURCE/$CHEMIN"; sleep 2; done
fi
```

`OID_COUNT` doit valoir exactement 1 (`count=0` : chemin absent ou extraction vide ; `count>1` : chemin ambigu) ; dans les deux cas, ne pas lire de blob. Ne pas utiliser `git show "origin/main:$CHEMIN"` sous Git Bash : MSYS réécrit l'argument et Git répond `ambiguous argument` (constaté le 2026-10-26). Trois échantillons identiques à 2 s d'intervalle établissent la stabilité des sources.
